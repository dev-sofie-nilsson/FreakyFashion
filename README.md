# Freaky fashion grupprojekt

### Clone project and install dependencies

1. `git clone https://github.com/Sebaelo/Grupparbete-backend.git`

2. `npm install`

### Recreate database

1. Copy queries from `data/FreakyFashion.sql`

2. Replace line 3 `data/FreakyFashion.db` query editor.  
   **_IMPORTANT: Keep line 1 in query editor!_**

3. Run queries

### Create your own branch and add to remote

### Start dev server

`npm run dev`
